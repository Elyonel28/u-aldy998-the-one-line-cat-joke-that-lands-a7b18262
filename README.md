# The One-Line Cat Joke That Lands

One joke about cats, one line, under 200 characters — written to
`/output/entry.txt` by `main.ts` (Node 22 stdlib only).

> My cat stares at the wall for an hour, then looks at me like I'm the one who can't see the ghost.

Setup: the cat stares at nothing. Turn: the cat blames *you* for not
seeing the ghost. Short, visual, retellable — no tired pun.

node main.ts
